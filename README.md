# Swarm Navigation Workspace

This repository contains the ROS 2 workspace for the **Centralized Intelligence for Dynamic Swarm Navigation** project (Inter IIT Tech Meet 13.0).

## Workspace Structure
- `src/singular_brain/`: The core centralized intelligence and perception node (YOLOv5 + 3D Tracking).
- `src/factorybot/`: ROS 2 compatible URDFs and Gazebo worlds for the swarm AMRs/AGVs.

Please see the individual `README.md` files inside `src/singular_brain/` and `src/factorybot/` for detailed installation and execution instructions.
